# 阅读指南

这份文档面向使用者：怎么把一篇英文 Markdown 调到「刚好有点难度」的状态，怎么把阅读过程沉淀成自己的词表，以及遇到问题时先看哪里。

---

## 一、第一次阅读：三次调整

### 1. 打开文稿

点「打开 Markdown」或按 `O`，选 `.md` / `.markdown` / `.mdown` / `.txt`；也可以直接把文件拖进页面。

文件只在浏览器里读取。不需要联网，也不会被上传。

### 2. 先按默认值读三段

默认设置是「隐藏前 1200 个高频词」+「难词优先」。先别急着调参数，读完三四段，再判断属于下面哪种情况：

| 你看到的现象 | 说明 | 怎么调 |
| --- | --- | --- |
| 满屏中文，几乎每句都有标注 | 阈值偏低，把你会的高频词也标了 | 滑块往右，加到 2000–4000 |
| 标注不多，但看不懂的地方没标 | 阈值偏高，或者词表缺该词 | 滑块往左；或用「取词标注」手动补 |
| 一个词被拆开标了两次（如 `machine`、`learning`） | 词组没被识别 | 确认「优先识别词组」是打开的 |
| 通篇没有标注 | 词频或中文开关被关了，或词表为空 | 看顶部 `＃` 和 `中` 两个按钮的按下状态 |

### 3. 再决定模式

- **难词优先**（默认）：只标阈值之外的词。适合泛读，页面干净。
- **全部标注**：所有有释义的词都标，包括 `the`、`of` 这类高频词。适合精读、校对译法，或者给完全零基础的材料做学习版。

「全部标注」下页面会非常密，通常只在精读一小段时用。

## 二、阈值参考

阈值是「隐藏前 N 个高频词」，`wordfreq` 排名越小越常见。下面只是起点，不是标准答案：

| 阅读材料 | 建议起点 |
| --- | --- |
| 中学 / 四级水平文章 | 800–1500 |
| 六级、考研英语阅读 | 1500–3000 |
| 雅思、托福阅读 | 2000–4000 |
| 通俗科普、技术文档 | 1200–2500 |
| 英文原版小说 | 3000–6000 |
| 学术论文、人文社科 | 4000–8000 |
| 只想看最生僻的词 | 8000 以上 |

判断标准只有一个：**读完一段，需要停下来想的词不超过三五个**。超过就降低阈值（标注更多），基本不用停就提高阈值（标注更少）。

同一个阈值不必贯穿整本书。专业章节可以临时拉高，人物对话多的章节可以拉低。

## 三、标注怎么读

### 颜色代表词频区间

侧栏「当前阅读」里的图例对应正文标注的深浅：

- **1k–5k · 中频**：认识概率较高，标注最轻
- **5k–15k · 低频**：值得留意
- **15k+ · 罕见**：专业词、生僻词

颜色只是提示，不影响是否标注。

### 点击释义切换义项

一个词可能有多个候选释义。直接点中文标注，会在候选之间循环切换。当前显示哪一条不会永久保存，除非你在本地词典里明确选定（见下文）。

### `✓` 表示「我会了」

点标注旁的 `✓`：

- 这个词立刻从正文中移除标注；
- 它被加入**掌握词表**，之后打开任何文稿都不再出现；
- 词形变化一起生效（`running`、`runs`、`run` 这类规则形式一起处理；`ran` 这类不规则形式取决于词表是否直接收录）。

### 「典」表示「想看得更完整」

只有在启动本地词典服务（`./start.sh`）后才出现。点开可按词典分页浏览完整义项，并把某一条固定显示在正文该词旁边。

### 两个总开关

- 顶部 `中`（快捷键 `A`）：关闭后只隐藏中文，保留词频下划线，适合自测。
- 顶部 `＃`（快捷键 `F`）：关闭后完全恢复原文，适合校对排版或复制原文。

## 四、把阅读沉淀成词表

### 掌握词表 vs 生词表

| | 掌握词表 | 生词表 |
| --- | --- | --- |
| 怎么加入 | 点标注旁的 `✓`；或导入 `.txt` | 开启「取词标注」（`V`）后点正文单词 |
| 作用 | **不再标注** | **强制标注**，不受阈值限制 |
| 典型用途 | 清理已经认识的词，让页面变干净 | 锁住一直记不住的词，让它反复出现 |

两者互斥：标为已掌握会同时从生词表移除；对已掌握的词手动标注，会把它移回学习状态。

### 推荐的节奏

不要边读边点 `✓`，那会把阅读变成整理。更省力的做法是：

1. 一口气读完一节，遇到不认识的词用「取词标注」点一下（不改动阅读节奏）；
2. 读完一节后回到侧栏，把「生词表」里已经记住的词逐个取消，或直接留在里面，等下次阅读再巩固；
3. 真正确认掌握的词，再从标注旁点 `✓`。

### 导入与导出

- **导入**：接受 `.txt`、`.csv`、`.md`。每行一个词，或用逗号、空格分隔都行。程序只提取其中的英文单词，统一转小写，并去掉撇号和连字符（`don't` 会变成 `dont`），所以导入前不需要清洗格式。
- **导出**：把当前掌握词表存成 `known-words.txt`，一行一个，已排序。建议每周导出一次做备份。

词表保存在浏览器本地存储里，**不会跨浏览器、跨设备同步**。换浏览器或换电脑时，用导出 / 导入迁移。

## 五、长文怎么读

### 目录

侧栏「文章目录」优先使用 Markdown 标题。如果文稿没有标题，会按章节标记、分隔线、段落结构自动划分，并在标题旁显示「自动」徽标。按 `T` 可以快速跳到目录。

### 书签

- `B`：在当前位置添加书签，书名可以来自最近的章节标题或该段摘录；
- `Shift + B`：打开本书签列表，点击跳转，也可以单独删除；
- 书签按文稿保存，每篇可以有多个。

### 高亮

选中要标记的文字，按 `H` 或点顶部「高亮」。点击黄色区域即可取消。高亮同样按文稿保存。

### 沉浸阅读

按 `I` 或点「沉浸阅读」：工具栏、侧栏、页眉页脚、书签条全部隐藏，只留下正文；屏幕顶部保留一条极细的阅读进度线，右下角胶囊显示当前百分比。按 `Esc` 或 `I` 退出。

进入和退出沉浸模式时会自动对齐回原来读到的那一段，不会跳位。

### 进度

滚动时自动保存位置。再次打开同一篇文稿会回到上次的位置。刷新页面时，如果文稿不超过 1.5 MB，还会自动恢复上次打开的文稿。

## 六、复杂排版

### 公式

`$...$` 行内公式和 `$$...$$` 独立公式由本地 KaTeX 渲染，支持常见的上下标、分式、矩阵、`\tag` 编号。公式区域不参与词频标注；公式过宽时可在公式区域内横向滚动。

### 表格与代码

Markdown 表格正常渲染。代码块（```）和行内代码不参与标注，保持原样。

### 图片

Markdown 图片语法 `![说明](路径)` 可用。注意原始 HTML 的 `<img>` 标签会被安全过滤，请使用 Markdown 语法。

### 允许的 HTML 标签

支持 `<sup>`、`<sub>`、`<small>`、`<span>`、`<abbr>`、`<mark>`、`<kbd>`、`<del>` 等排版标签，也兼容中文弯引号书写的属性。脚本、事件属性、`style` 中的不安全内容会被过滤掉。

### 外链

正文里的 http/https 链接会在新标签页打开，并带上 `noopener noreferrer`。

## 七、个人数据管理

### 数据存在哪里

全部在浏览器本地存储，键名以 `reading-room:` 开头。文稿按「内容哈希 + 文件名」区分，所以改文件名或改内容会被当成新文稿，进度和书签不会继承。

### 备份

- 词表：侧栏「导出」得到 `known-words.txt`。
- 书签、高亮、进度：没有导出入口，只存在本机浏览器里。

### 清理

侧栏「我的词表」里的「清空」只清掌握词表。要彻底重置，可以在浏览器开发者工具里删除 `reading-room:` 开头的本地存储条目。

## 八、常见问题

**打开后没有中文标注。**
依次检查：顶部「显示词频」是否亮起（`F`）；「显示中文」是否亮起（`A`）；阈值是否被拉得过高；该词是否已在掌握词表里。如果这个词根本不在内置词表（39,863 个词频条目 / 38,479 个单词释义），需要手动「取词标注」。

**标注出现得断断续续。**
这是视口懒标注的设计：只有滚到附近（上下约 600px）的段落才会生成标注。继续滚动就会补齐。侧栏统计的也是当前已标注的范围，不是全文。

**刷新后进度丢了。**
可能原因：文稿被改名或内容变了；文件超过 1.5 MB；浏览器禁用了本地存储；或者你换用了 `http://` 打开（`file://` 与 `http://127.0.0.1` 是不同源，各有一份存储）。

**没有「典」按钮。**
说明本地词典服务没连上。检查：是否用 `./start.sh` 启动；`node` 是否可用；8765–8770 端口是否被占用；侧栏「本地词典」里是否至少勾选了一部词典。

**中文释义不准确。**
内置释义是词对词的简明提示，来自 CC-CEDICT 的反向整理，没有语境判断。多义词请点标注切换候选；需要精确义项时用本地 MDX 词典，选定后会固定显示。

**公式没渲染。**
确认公式被 `$` 或 `$$` 包裹；确认用的是 KaTeX 支持的命令；确认公式不在代码块里。

**想让某个词永远不标注。**
点它的 `✓`，或把它加入导入的 `.txt` 词表。

**想给一个已掌握的词重新加标注。**
开启「取词标注」（`V`）后点它，或选中后按 `L` 从词典挑一条释义。两种操作都会把该词移出掌握词表。

**手机上侧栏挡住正文。**
左上角 `☰` 打开 / 关闭侧栏；`T` 在窄屏下也会切换侧栏。

**换浏览器后词表空了。**
本地存储不跨浏览器。用「导出」拿到 `.txt`，在新浏览器里「导入词表」。

## 九、命令速查

```bash
./start.sh                 # 启动词典服务并打开页面
./start.sh --port 8766     # 指定起始端口
./start.sh --stop          # 停止词典服务

cp dictionaries.example.json dictionaries.json   # 自定义词典目录
```

不启动服务也能阅读，只是没有「典」按钮和完整词条面板。
