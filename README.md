# 词频阅读室 · Markdown Reading Room

一个完全在本地运行的 Markdown 英文阅读器。打开文章，它按英语词频隐藏你已经熟悉的词，把简体中文释义直接标在原文之后，让生词留在句子里，而不是被丢进另一个词典窗口。

- 不需要安装依赖，不需要构建，不联网
- 文稿、词表、书签、进度全部保存在本机
- 可选联动本地 MDX 词典（GoldenDict 词典库）

## 它解决什么问题

英语泛读里最消耗注意力的动作是「打断」：一句话读到一半，遇到生词，切窗口、查词、回到原文、重新找位置。词频阅读室的做法是减少这种打断：

1. 先用词频筛掉你大概率已经会的词，只标真正需要的；
2. 把中文提示放在词后面，不弹窗、不遮挡原文；
3. 词组优先整体标注，避免 `machine learning` 被拆成两个词各自翻译；
4. 你觉得已经掌握的词点一下 `✓` 就永久隐身，词表跟着你走。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 词频标注 | 按 `wordfreq` 排名隐藏前 N 个高频词，阈值 0–12000 可调，默认 1200 |
| 两种标注模式 | 「难词优先」只标阈值之外的词；「全部标注」标注所有有释义的词 |
| 词组优先 | 识别 2–5 词组成的固定搭配，优先整体标注；未命中再退回逐词标注 |
| 中文紧跟原词 | 释义以轻量标注附着在词后，点击可切换候选义项 |
| 视口懒标注 | 只处理当前屏幕上下约 600px 的段落，滚动时增量生成；侧栏统计的是当前阅读范围 |
| 掌握词表 | 点 `✓` 把词移出标注；支持导入/导出 `.txt`，词形变化一起生效 |
| 生词表 | 开启「取词标注」后点正文任意单词即强制标注，不受阈值限制 |
| 多书签 | 每篇文稿可存多个书签，按章节标题或摘录跳转，支持单独删除 |
| 自动目录 | 优先用 Markdown 标题；无标题时按章节标记、分隔线、段落结构推断，并标注「自动」 |
| 高亮 | 选中正文后高亮，点击黄色区域取消，按文稿保存 |
| 沉浸阅读 | 隐藏工具栏、侧栏、页眉页脚，只留正文，顶部有极细进度线 |
| 阅读进度 | 自动保存位置，重开同一篇回到上次读到的地方；也可恢复上次打开的文稿 |
| LaTeX | 本地 KaTeX 渲染 `$...$` 与 `$$...$$`，公式区域不参与词频标注 |
| 安全 HTML | 支持 `<sup>`、`<sub>`、`<small>`、`<span>` 等排版标签；脚本、事件属性、不安全样式会被过滤 |
| 本地词典 | 可选。读取本机 MDX 词典，按词典分页列出义项，选定后固定显示 |
| 浅色 / 深色 | 一键切换主题 |
| 移动端 | 窄屏时侧栏改为抽屉，可从左上角打开 |

## 快速开始

要求：一个现代浏览器（Chrome、Edge、Firefox、Safari 的近期版本）。不需要 Node，也不需要安装任何依赖。

### 方式一：直接打开

双击 `index.html`，或把它拖进浏览器窗口。然后点「打开 Markdown」，选择本地 `.md`、`.markdown`、`.mdown` 或 `.txt` 文件；也可以把文件直接拖进页面。

这是最轻量的用法，全部功能可用，只是没有「典」按钮（本地词典联动）。

### 方式二：带本地词典启动

```bash
./start.sh
```

脚本会在后台启动 `server.mjs`（仅监听 `127.0.0.1`），然后用 `file://` 打开页面。页面会自动探测 8765–8770 端口；探测不到也不影响阅读，只是没有词典联动。

```bash
./start.sh --port 8766   # 指定起始端口
./start.sh --stop        # 停止后台词典服务
```

停止服务后，页面照常可读。

### 方式三：先看示例

点欢迎页的「阅读示例」或侧栏的「先看示例文章」，会载入内置的 `sample.md`，用来快速体会标注效果。

## 阅读工作流

### 1. 先定难度区间

侧栏「词频标注」里的滑块是**隐藏前 N 个高频词**。N 越大，标注越少。默认 1200 适合一般科普、技术文档；读原版小说或学术论文时可以调到 3000–6000；如果只想看最生僻的词，可以拉到 8000 以上。

「难词优先」下只有排名大于阈值的词会被标注；「全部标注」会标注所有在词表里有释义的词（仍然跳过你标为已掌握的词）。

### 2. 建立自己的词表

- 阅读时点击中文标注旁的 `✓`：这个词从正文标注中移除，并加入**掌握词表**，之后打开任何文稿都不再标注。
- 顶部「取词标注」（`V`）打开后，点正文里任意单词：它会被加入**生词表**并强制标注，不受阈值限制。
- 两个词表互斥：标为已掌握会同时从生词表移除；对已掌握的词手动标注，会把它移回学习状态。

词形变化会跟着走：复数、过去式、`-ing`、`-ly`、所有格按规则还原到词根，一起生效。

侧栏「我的词表」里可以搜索、逐个移回、批量导入或导出 `.txt`（每行一词）。

### 3. 需要时再查完整词典

```bash
./start.sh
```

服务启动后，每个中文标注旁多出「典」按钮；也可以选中正文里的单词按 `L`。面板按词典分页列出义项，中英混排的条目会拆成「EN」和「中」两段，点哪段就把哪段固定到正文；选择按词条记住，可在侧栏「本地词典」里一键清除。面板里还能「在 Goldendict 中打开」完整词条，或展开词典原始排版。

### 4. 标记位置

- `B` 在当前位置添加书签，`Shift + B` 打开本书签列表，按章节或摘录跳转。
- 选中正文后按 `H` 或点「高亮」；点击黄色区域取消。
- `I` 进入沉浸阅读，`Esc` 退出。进入和退出时会自动对齐回原来读到的那一段。

## 侧栏分区

侧栏按使用顺序分成七块，从上到下就是一次阅读的典型路径：

1. **OPEN**：选择文稿，或载入示例。
2. **LEVEL**：词频阈值、标注模式、词组开关。
3. **COMFORT**：正文字号（15–26px，默认 19px）、栏宽（560–1040px，默认 760px）。
4. **VOCABULARY**：掌握词表与生词表的导入、导出、管理与清空。
5. **DICTIONARY**：词典服务状态、勾选参与的词典、清除已选释义。只有启动服务时才出现内容。
6. **SIGNAL**：当前阅读范围的可见标注数、词组数、待学词次、不同词数，以及词频图例。
7. **OUTLINE**：根据标题或段落结构生成的文章目录。

## 本地词典联动（可选）

### 词典从哪里找

服务启动时会读取两处配置：

1. `dictionaries.json` 里的 `roots`（数组，可写多个目录）；
2. GoldenDict 配置 `~/.config/goldendict/config` 中的 `<path>` 词典目录。

两处结果合并去重后，递归扫描目录下的所有 `.mdx` 文件。想手动指定目录，复制示例文件再改：

```bash
cp dictionaries.example.json dictionaries.json
```

```json
{
  "roots": ["/path/to/your/mdx/dictionaries"],
  "exclude": []
}
```

`dictionaries.json` 属于个人配置，已加入 `.gitignore`，不会被提交。

### 运行方式

- 只监听 `127.0.0.1`，不对外暴露。
- 默认端口 8765，被占用时自动向后尝试；页面探测 8765–8770。
- 词典文件原地读取，不复制、不改写 GoldenDict 的数据。
- 最多同时打开 5 部词典；单条词条渲染上限 60000 字符。

### 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查，返回已索引词典数量与扫描根目录 |
| GET | `/api/dictionaries` | 列出词典：id、名称、子目录、方向、体积 |
| GET | `/api/lookup?word=...&dict=...` | 在指定词典中查词，返回义项 |
| POST | `/api/open-goldendict` | 用 `goldendict` 命令打开完整词条 |

服务同时也能托管静态页面（`http://127.0.0.1:8765/`），但**建议使用 `start.sh` 的 `file://` 方式**：`file://` 和 `http://127.0.0.1` 在浏览器里是两个不同的源，本地存储不互通，换成 HTTP 打开会看到另一套词表和进度。

## 数据与隐私

- 页面不发起任何外部网络请求。除可选的 `127.0.0.1` 词典服务外，没有任何接口调用。
- Markdown 文件只在浏览器内读取，不会上传。
- 本地存储键都以 `reading-room:` 开头，可以按需清理：

| 键 | 内容 |
| --- | --- |
| `reading-room:prefs:v1` | 阈值、模式、字号、栏宽、主题等偏好 |
| `reading-room:known:v1` | 掌握词表 |
| `reading-room:forced:v1` | 生词表 |
| `reading-room:glosses:v1` | 手动选定的词典释义 |
| `reading-room:last-document:v1` | 上次打开的文稿（用于刷新后恢复） |
| `reading-room:progress:v2` | 每篇文稿的阅读位置 |
| `reading-room:bookmarks:v3` | 每篇文稿的书签 |
| `reading-room:highlights:v1` | 每篇文稿的高亮 |

- 文稿按「内容哈希 + 文件名」区分，改名或改内容会被视为新文稿。
- 超过 1.5 MB 的文稿不会写入本地存储，刷新后不会自动恢复，但本次会话照常可读；建议先把词表导出备份。

## 已知限制

- **释义是词对词的简明提示**，不是语境翻译。多义词请点击标注切换候选，或结合上下文判断。
- **词形还原是规则匹配**，覆盖 `-s`、`-es`、`-ies`、`-ing`、`-ed`、`-ly` 和 `'s`。不规则变化（如 `went`、`children`）要看词表本身是否直接收录。
- **词频基于通用英语语料**，对专业术语、人名、缩写的判断可能偏保守。
- **自动目录是启发式的**：没有标题时按章节标记、分隔线、段落结构推断，可能与你心里的章节划分不完全一致。
- **标注是增量生成的**，侧栏统计只覆盖当前已进入阅读范围的段落，不是全文统计。
- 浏览器禁用本地存储时，阅读本身不受影响，但偏好、词表、进度、书签都不会在刷新后保留。
